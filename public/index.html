Qué ocurre al desactivar

El panel administrativo continúa disponible para que puedas volver a activarla. Las solicitudes de validación de keys reciben un estado temporal de API desactivada. El estado queda guardado en PostgreSQL, así que un reinicio/deploy no lo cambia.
